# **App Name**: Coral Cart

## Core Features:

- Cuadrícula de Productos: Mostrar productos en un diseño de cuadrícula con imágenes, descripciones y precios, similar a Airbnb.
- Búsqueda de Productos: Implementar una funcionalidad de búsqueda robusta con entrada de palabras clave y sugerencias en tiempo real.
- Filtrado de Productos: Permitir el filtrado por rango de precios, categoría y otros atributos relevantes.
- Página de Detalles del Producto: Proporcionar una página de detalles del producto con imágenes de alta resolución, especificaciones, reseñas e información del vendedor.
- Carrito de Compras: Permitir a los usuarios agregar artículos seleccionados a un carrito de compra persistente con ajustes de cantidad.
- Recomendaciones Impulsadas por IA: Sugerir productos relacionados o complementarios para mejorar la experiencia de compra. Utilice una herramienta de IA para determinar qué productos son similares.
- Selección de País/Idioma: Permitir al usuario elegir su país y cambiar la aplicación al idioma correspondiente.

## Style Guidelines:

- Color primario: Coral claro (#FF7F50) para aportar calidez a las imágenes de los productos.
- Color de fondo: Blanco suave (#F5F5F5) para dar prominencia a los productos y mantener la limpieza.
- Color de acento: Melocotón intenso (#FFCBA4) para interacciones y resaltados clave.
- Fuente del cuerpo: 'Inter', sans-serif, para descripciones de productos y elementos de interfaz limpios y legibles.
- Fuente del título: 'Space Grotesk', sans-serif, para títulos de productos y mensajes clave; si se anticipa un texto más largo, utilice 'Inter' para el cuerpo.
- Utilice iconos minimalistas para mejorar la usabilidad.
- Siga un diseño basado en cuadrículas para los listados de productos para que se alinee con el diseño minimalista.
